# Инструкции для Codex и других AI-агентов

## Источник правды

- Единственная актуальная версия проекта находится в `deevalexandr10-prod/zmeika-igra`.
- Перед изменениями изучить `README.md`, `PROJECT_STATUS.md`, `package.json` и существующую структуру.
- Перед началом работы проверить ветку и состояние Git; не перезаписывать пользовательские изменения.

## Контекст проекта

- Основной код приложения находится в `app/`.
- Статические материалы публикации находятся в `docs/`.
- Проект использует Node.js 22+, pnpm, Vinext/Next.js, React и TypeScript.

## Команды

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
pnpm lint
pnpm test
```

## Безопасность

- Никогда не коммитить пароли, токены, ключи, cookie, реальные `.env` и персональные данные.
- Новые переменные окружения документировать только безопасными заглушками в `.env.example`.
- Не удалять и не перезаписывать пользовательские изменения без прямого разрешения.

## Передача работы

- Делать изменения небольшими и проверяемыми.
- Для рискованных или крупных изменений использовать отдельную ветку и pull request.
- После существенной работы обновлять `PROJECT_STATUS.md`.
- Не выдумывать решения, владельцев и сроки. Неизвестное помечать как неизвестное.
- В отчёте точно разделять реально выполненные проверки и рекомендации для будущей проверки.
